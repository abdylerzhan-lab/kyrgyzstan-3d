# Кыргызстан 3D

Демо 3D-гида по памятникам Кыргызстана для конкурса «100 идей для Кыргызстана» (2026). Башня Бурана: 3D-модель (сейчас и условная реконструкция), гид с вопросами.

Модель построена в Blender по фото с Wikimedia Commons и справочным размерам.

## Источники данных
- Спутниковый снимок: Sentinel-2 cloudless (s2maps.eu, EOX), CC BY-NC-SA 4.0 — только некоммерческое использование.
- Рельеф: AWS Terrain Tiles (Mapzen, открытые данные).
- Граница КР: geoBoundaries (CC BY 4.0).
- Фото: Wikimedia Commons, авторы и лицензии — в media/places.json.
- Дома, дороги, тропы и названия (Сулайман-Тоо): © участники OpenStreetMap, ODbL.
